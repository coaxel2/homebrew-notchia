# homebrew-notchia

Homebrew tap for [NotchIA](https://notchia.app) — bring your MacBook notch to life.

## Install

```bash
brew install --cask coaxel2/notchia/notchia
```

That's it. Brew handles the download, signature handling, and Applications copy automatically. No terminal warnings, no Gatekeeper pop-up.

## Update

```bash
brew upgrade --cask notchia
```

## Uninstall

```bash
brew uninstall --cask notchia
```

To also remove user data:

```bash
brew uninstall --cask --zap notchia
```
